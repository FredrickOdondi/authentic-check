# Authentic Check

**AI-powered document integrity analysis.** Upload an essay or report and get a report with a plagiarism score, a probability that the text is AI-generated, and the flagged passages highlighted.

## Features

- Drag-and-drop upload for **PDF** (pdf.js) and **Word** (.docx via mammoth) documents
- **Plagiarism score:** content similarity with existing sources
- **AI content score:** probability the text was machine-generated
- **Flagged sections** highlighted in the results view
- Exportable integrity report

## Stack

React · TypeScript · Vite · Tailwind CSS · shadcn/ui · Framer Motion · pdf.js · mammoth

## Run locally

```bash
npm install
npm run dev
```
